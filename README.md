# Transcriber App

A small command-line tool that transcribes audio and video files to plain text using
[OpenAI Whisper](https://github.com/openai/whisper).

Given an audio/video file, it writes the transcription to a sibling `.txt` file.

## Features

- Transcribes common audio formats (`.mp3`, `.m4a`, `.wav`, `.ogg`, …)
- Transcribes video formats (`.mp4`, `.mov`, `.mkv`, …) by extracting the audio track
- Selectable Whisper model size (`tiny` → `large`) to trade speed for accuracy
- Language selection, or automatic language detection
- Output saved next to the input file as `<name>_transcription.txt`

## Requirements

- Python 3.9+ (this project was set up with Python 3.12)
- [`openai-whisper`](https://pypi.org/project/openai-whisper/)
- [`filetype`](https://pypi.org/project/filetype/)
- **ffmpeg** installed and available on your `PATH` — Whisper uses it to decode media.

The repo ships with a pre-built virtual environment in `.venv/`, which already
contains all dependencies (including PyTorch). If you are using that environment,
you can skip the installation step below.

## Installation


```bash

python3 -m venv .venv
```

```bash

brew install ffmpeg
```

## Usage

```bash
python transcriber.py [options] FILE
```

### Arguments

| Argument | Description | Default |
| --- | --- | --- |
| `FILE` | Path to the audio or video file to transcribe. | — (required) |
| `-l`, `--language` | Language code of the audio (e.g. `en`, `es`, `fr`, `de`, `pt`, `it`, `ja`, `zh`). Use `auto` for automatic detection. | `es` |
| `-m`, `--model` | Whisper model size: `tiny`, `base`, `small`, `medium`, `large`. Larger models are slower but more accurate. | `medium` |
| `-h`, `--help` | Show the help message and exit. | — |

### Examples

Transcribe a file with the defaults (Spanish, `medium` model):

```bash
python transcriber.py recording.mp3
```

English audio using the fast `small` model:

```bash
python transcriber.py -l en -m small lecture.m4a
```

French video with the most accurate model:

```bash
python transcriber.py --language fr --model large video.mp4
```

Let Whisper detect the language automatically:

```bash
python transcriber.py -l auto interview.wav
```

## Output

For an input file `recording.mp3`, the transcription is written to:

```
recording_transcription.txt
```

The file contains the raw transcribed text.

Example console output:

```
Loading Whisper model 'medium'...
Transcribing 'recording.mp3' (language=es)...
Transcription saved to 'recording_transcription.txt'
```

## How It Works

1. The file path is validated with `filetype` — the file must be detected as
   `audio/*` or `video/*`.
2. The chosen Whisper model is loaded (downloaded on first use and cached
   locally by Whisper).
3. `model.transcribe()` decodes the media and produces the text.
4. The text is saved to `<name>_transcription.txt` with UTF-8 encoding.

## Notes & Tips

- **Model download:** The first run downloads the selected model, which can take
  a while depending on your connection and the model size.
- **Performance:** With a CUDA-capable GPU, Whisper uses it automatically.
  `fp16` is disabled in this script, so it works on CPU-only machines as well.
- **Large files:** Transcription time scales with file length and model size.
  Start with `tiny` or `base` to verify your setup, then switch to a larger
  model for better accuracy.
- **Errors:** If no file is provided or the file is not a valid audio/video
  type, the script prints an error to stderr and exits with status code `1`.
